# 普通 HTML 个人文档自动保存

网站维护运行时保存与恢复层，老板上传的正文和指南逐字保持原样。普通 HTML 可新建个人文档，不要求修改原文件或追加接口；自带接口的模板仍使用自己的业务状态。预览不保存个人填写内容，请从“新建文档”进入。

## 运行流程

发布弹窗 → 原文件在隔离窗口完成初始化与恢复往返检查 → 原文/哈希核对后启用 → 员工新建本人文档 → 自动保存结构化数据 → 独立回执读回 → 刷新重放原操作并继续填写。

通用模块采集表单值、勾选、多选、可编辑文字及图片，记录动态按钮、双击、选择和文件操作。恢复时调用原事件处理函数，保留逐行监听器和计算闭包，不把动态 DOM 复制成失去行为的静态页面。只通知实际改变的文本字段，避免重复调用原图片地址处理函数而清空已上传的文件。确认框/输入框的回答一并保存，恢复不重复打印、下载或打开链接。临时图片地址转换为实际像素，文件保存实际字节；大字符串去重后存储一次，编号按内容排序，避免 jsonb 属性排序影响恢复检查。长操作记录使用有限的恢复等待时间，上限两分钟。

数据库跟随迁移 `20261009020109_generic_html_document_saving.sql`，仅取消文件接口声明对新建文档的限制并更新审计说明。原权限、版本锁定、防重、冲突、回执和 10 MiB 上限保留。原能力生成列继续记载文件自带接口声明，供审计使用，不决定页面入口或保存权限。没有模板正文、指南、当前版本或历史个人文档的批量更新。

## 验证边界

未运行全站 E2E或穷尽所有 HTML 内部功能。外部脚本、嵌入网页、联网提交仍不属于受支持的单文件模板。画布绘制、无法由界面操作还原的私有状态、浏览器之外的外部数据及所有公司配置导入/导出组合尚未验证；此类状态可使用模板自带的结构化接口。发布初始往返检查不等于所有内部功能都已通过验证。实际 PDF 导出和托管后台构建编号尚未验证。

生产全新共享模板的上传写入不通过修改老板模板来验收；对应流程已经本地完整执行。GitHub、Supabase Cloud、线上运行版本和真实 Cloud 保存结果分别核对后记录，不能仅以推送成功或网页能打开报告上线。
