# 模板文档归档与本地验收

## 使用流程与权限

公司模板 → 新建文档 → 先选择可管理的文件夹 → 创建并编辑。每次手动保存重新选择位置，默认当前文件夹；换位置更新同一编号的文档。自动保存更新当前位置，不打开弹窗。弹窗期间暂停自动提交，确认采集最新内容并串行提交，取消恢复自动保存。另存一份选择名称和目标位置。

归档请求失败后取消弹窗，恢复的自动提交只更新内容，不重送已取消的移动意图。如果请求其实已经落库而回执丢失，旧修订会触发冲突，停止提交并要求重新打开真实保存结果；取消不能撤销已经提交的事务。这两种情况都通过页面断网和独立查库验证。

资料库 → 模板文档 → 继续编辑、重命名、另存一份、移动或删除。上传文件与模板文档在数据库先合并，再统一搜索、排序、计数及每页 20 项分页。编辑入口为 `/<workspace>/documents/templates/<documentId>`，返回定位对应人员或客户的文件夹。公司模板页面仅显示公司发布的模板。

权限沿用资料库：管理员管理全部；开通批发业务的业务员管理本人和所有客户资料，可以编辑其他员工存入客户目录的文档；其他岗位沿用原范围。客户只读本人明确共享的内容。手动保存、复制和移动到共享资料，包括默认已经共享的位置，均要求勾选确认；自动保存保留当前目录。读取正文、指南、绑定历史版本、操作回执均重新检查当前文件夹权限。

选择器只接收可管理档案，支持人员/客户搜索，目录选项包含完整祖先路径。长路径在展开列表中换行。模板填写继续沿用电脑端限制，手机可在资料库管理条目；本次没有增加统一 PDF 转换。普通 HTML 与自带 `PT5Template` 接口继续恢复原版并编辑，打印、下载和版本锁定能力保留。
