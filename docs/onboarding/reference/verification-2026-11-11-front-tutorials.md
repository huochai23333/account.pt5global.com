使用现有 Web 服务、本地 Auth 和真实线索查询。每轮准备一个随机学习管理员和两条 UUID 线索。练习一至三按[前端修改步骤](../tutorials/first-changes.md)临时编辑两份文案和三个展示组件。通过浏览器中的项目语言偏好分别进入中英文页面，运行 1440px 与 390px 的四组检查。

| 练习 | 结果 |
| --- | --- |

## 线索领取和联系

按[线索领取步骤](../tutorials/sales-lead-flow.md)在页面双击领取自己的专属样本。数据库最终状态为 `claimed`，负责人为本次管理员，领取周期正好 1 条。刷新并搜索同一编号后仍在「我的线索」，领取入口消失。随后从详情记录一次联系，独立确认联系行、作者、领取周期、联系时间与线索修订。联系计数为 1，`first_contact_at` 等于该记录的联系时间。
