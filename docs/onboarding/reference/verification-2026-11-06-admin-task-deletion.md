# 管理员任务删除与附件清理验证

本批按关键写入验证。任务删除必须得到正确任务编号的回执，并通过独立查询确认任务已经消失。随后分别检查任务附件与提审附件的清理结果。任务仍在或读回中断时保留附件，某组对象未确认消失时返回 `partial_failed`。删除确认前拦截重复请求。创建时若附件上传失败且删除补偿未确认，返回任务列表供用户核对。

## 复现与结果

- 故障注入去掉独立读回检查，使模拟返回正确删除编号但任务仍存在，测试检测到错误清理。复跑覆盖正常删除、仍有任务、读回失败、零影响、错编号、删除响应中断和提审对象删除无效。Storage 操作使用网络边界模拟。
- 无端口、无网络的隔离 PostgreSQL 使用当前真实结构和 RLS。客户角色删除影响 0 行，管理员删除任务 `b6000000-0000-4000-8000-000000000002` 影响 1 行，重复删除影响 0 行。独立查询确认任务、任务附件登记、领取、提审和提审附件登记各为 0 行。回滚后账号计数为 0。
- 主本地数据库保持旅游停用，计划任务和外部请求队列均为零。隔离数据库脚本与结果位于后端仓库 `output/task-deletion-20261106/`。专属容器与结构快照已清理。
