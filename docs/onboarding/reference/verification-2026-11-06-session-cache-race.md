后续[真实浏览器迟到响应](verification-2026-11-11-session-late-browser.md)补齐退出后的旧Auth取消，以及跨标签账号切换后旧权限响应实际送达，共8个中英文／桌面手机组合。下面保留本次历史隔离用例与当时浏览器范围。

2026-11-06。按 Web 质量门禁的行为路线验证。受影响范围是浏览器会话和权限读取、使用它们的工作台资料页。服务端准入仍通过每次请求验证的身份和数据库权限。[认证读取链路](../explanation/auth-read-paths.md)

| 竞态 | 验证结果 |
| --- | --- |
| 退出后四类旧读取返回 | 会话、用户、声明和岗位均返回空值，下一次读取仍是退出状态 |
| 旧权限请求晚于新请求启动 | 旧结果丢弃，旧请求结束不会清掉正在执行的新请求，新调用复用同一次读取 |
| 显式重置 | 尚未返回的请求立即失效，下一次读回新用户 |
| 组合身份时账号切换 | 首次会话通知保留首轮核验；等待岗位时切换账号，旧组合返回空值。下一次组合的用户、会话和岗位均来自新账号 |
