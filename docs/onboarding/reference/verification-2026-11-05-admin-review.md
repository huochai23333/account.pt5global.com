# 审核中心回执与终态验证

2026-11-05。使用既有本机 Web、Auth、数据库和 Storage。通过 [Playwright 网络路由](https://playwright.dev/docs/network)注入空回执及连接中断。媒体使用合成图片及真实本地对象，审核由页面发起。

## 复现与修复

旧页面接到 HTTP 200 空回执时提示媒体审核通过，同时移除待审卡片。数据库仍为待审核。原失败日志 `2026-11-05T14-10-33-434Z-00bd7c66-c778-42bf-a20b-966a133e1edd`，误报出现在测试错误快照。

空回执或终态不匹配时，提示核对并保留原卡片。媒体和隐私审核独立读取目标记录，检查申请人、审核人、时间与决定。响应丢失时只查原记录。同步按行锁拦截重复确认，审核完成时忽略先前发出的列表读取。资料修改继续校验原申请编号及审核状态。
