# 管理员任务筛选与地址验证

本批按行为改动验收。原重置回调依次清空搜索和角色，两次更新读取同一次渲染的旧筛选，第二次会覆盖第一次。现在由 React 状态队列依次合并，回到第一页并保留当前历史状态。地址变化后舍弃旧草稿，翻页优先于延迟筛选。列表的角色、状态和文本匹配从路由状态中提取。

## 复现与范围

- 故障注入改为每次都以旧地址为基准，合并测试检测到残留搜索词。恢复后 3 项定向合同通过，覆盖双筛选重置、历史状态、跨地址草稿、标签保留、特殊字符及领取记录状态。
- 本批验证查询参数及客户端筛选，没有业务写入。共享本地环境保持旅游停用，启用计划任务和外部请求队列均为零。
