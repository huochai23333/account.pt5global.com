# 任务类型写入与独立读回验证

本批按关键写入验证。类型的创建、编辑和停用都按同一编码确认结果。创建使用数据库生成的编码，编辑和停用核对输入编码。返回形状通过后再次读取目录。写入凭证须包含真实启用状态和金额，避免显示层的默认值替代数据库凭证。管理员和执行看板也共用类型目录读取。

## 复现与结果

- 故障注入改为直接采用停用回执，合同检测到目录仍启用却被判定成功。恢复独立读回后 4 项定向合同通过，覆盖创建编码、编辑错字段、停用旧状态、错误编码、空记录、空金额和权限失败。
- 无网络、无端口的隔离数据库执行现有函数。创建时独立核对 1 行、默认佣金 25.125 和启用状态。编辑和停用后，仍是编码 `task_type_29c08ca1d8884098`，名称为 `Changed fixture`，说明为空、默认佣金为 17.375，启用状态为 false。未知编码和非管理员写入被拒绝。事务回滚后专属账号为 0。
- 共享本地数据库保持旅游停用，普通登录角色没有停用函数执行权限，启用计划任务与外部请求队列均为零。隔离 SQL 和日志保存在后端仓库 `output/task-type-20261106/`，专属容器和结构快照已清理。
