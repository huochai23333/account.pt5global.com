## 已有缺陷的复现与本地修复

旧迁移的 IN SCHEMA public REVOKE 无法抵消 PostgreSQL 全局 PUBLIC 默认函数执行权。修复前，在专属结构副本中以真实迁移角色 postgres 新建未显式授权的函数，匿名和登录角色均可执行。当前已有匿名函数清单仍为明确开放的公开入口，发现的是以后新函数的默认授权缺口。

通过 CLI 2.108.0 创建 20261106080447_private_new_function_defaults.sql。候选在非超级用户 postgres 下验证，再用 migration up --local 应用。本地版本集合由 232 变为 233，当前结构索引已重新导出。已有 public 函数 ACL 应用前后摘要一致，未改变现有 URL、接口、业务岗位或金额规则。

修复后，未授权探针的匿名与登录执行权均为 false，实际调用被拒绝；显式授予登录角色后函数返回 17。事务回滚后探针不存在。修复前、候选和应用后结果在后端 output/learning-function-defaults-20261106/，保留当前 ACL 前后快照、迁移日志和旧默认值作为核对及回滚资料。
