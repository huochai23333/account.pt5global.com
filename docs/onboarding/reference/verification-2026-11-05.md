## 缺陷与验证证据

- 邀请权限读取失败以前会折叠为“没有可用权限”。先复现，再区分读取失败、重试、成功空集合；失败日志 `2026-11-05T04-21-11-493Z-c21482c9-dacf-4d4a-86a5-03b060fcee74`，重跑证据包含双语。
- 预览缓存清空后，旧请求会回写并可能删掉新请求；临时失败也被缓存成空。定向两例修复前失败、修复后通过。页面回归随后发现预览组件自动重复签名，改为失败提示保留到关闭，重开才读。原失败快照及最终媒体凭证保留。
- 资料表单必填星号造成精确标签定位超时；改用输入框角色和无障碍名称。早期超时留下的两个专属员工账号按已核对编号限定清理。员工夹具现在有独立 teardown 和时间预算，清理同时读回用户、布局、资料申请。
- 英文媒体验收曾在刷新未就绪时点击，数据库与对象已删除，页面弹窗断言失败；重新等待页面资源并显式断言空态。公开登录回归曾遇文档目录截图写入错误，已改为 Playwright 用例自己的输出路径。
- `supabase functions serve` Windows 包装程序复现 `ENAMETOOLONG`；同一安装目录的 `supabase-go.exe` 使用同一项目和本地配置启动成功。未新建第二个 Web 服务。
