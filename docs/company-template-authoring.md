# 公司互动模板与自动保存

管理员上传 UTF-8 单文件 HTML（最多 5 MB）。系统原样保存文件及指南，不要求老板修改模板。员工选择“新建文档”时先选择资料库文件夹，填写内容自动保存到该文档；预览页面用于查看原版。

普通 HTML 由网站在隔离窗口安装通用数据采集层，保存输入框、文本域、下拉多选、勾选、可编辑文字与图片。动态增删行、选择及文件操作记录为结构化操作，恢复时先运行原模板，再通过原事件处理函数重建动态元素，因此逐行绑定的监听器与计算闭包仍能继续使用。文件保存实际字节，临时图片地址转换为实际像素；总数据上限 10 MiB。恢复不重复打印、下载、打开链接或询问已回答的确认框。

通用采集的验证对象是单文件工作表单。外部脚本、嵌入页面、联网提交仍受现有上传限制和沙箱限制。仅在脚本私有变量中保存、无法由界面操作还原的自定义状态，可用下列可选接口明确导出；不能把初始往返检查视作所有模板内部功能已穷尽验证。

```js
window.PT5Template = {
  version: 1,
  exportState() { return { customer: document.querySelector('#customer').value }; },
  importState(state) { document.querySelector('#customer').value = state.customer; },
  subscribe(notify) {
    document.addEventListener('input', notify);
    return () => document.removeEventListener('input', notify);
  }
};
```

接口返回 JSON 对象，支持同步或异步恢复。应包含动态行、图片、手动修改标记与计算依赖；恢复完成后再次导出必须完全一致。图片使用 data URL，不能仅导出临时 blob 地址。不直接存储可执行 HTML。原模板已有接口时，通用层不会覆盖它。

发布和正式打开均执行导出→恢复→再次导出检查，失败停止等待并提供重新打开入口。个人文档绑定不可变模板版本，模板更新或停用不改变已有文档。创建文档时先选择资料库文件夹；保存按当前文件夹权限、修订冲突检测、防重回执与独立数据库读回执行。有管理权限的内部员工可以协作编辑，只有查看权限的人员和客户不能保存修改。管理员模板正文与指南不由网站修复流程改写。

## 制作自检

1. 填写部分和完整内容，等“已保存”后刷新确认。
2. 新增、复制和删除动态行，刷新后继续修改金额与增删。
3. 选择、粘贴及替换图片，刷新检查实际图像。
4. 改变比例、打印设置、多选、勾选和手动编号，检查恢复与重新计算。
5. 更换模板版本后，确认旧个人文档仍使用原版。
