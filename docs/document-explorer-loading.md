# 资料库加载与布局验证

2026-10-10。本次仅修改 Global Web 资料库的读取体验、布局和通知展示。复用 localhost:3000 的单个开发服务器及本地 Docker 数据库；没有新增迁移或修改写入接口。

## 行为与模块

采用 `web-change-quality-gate` 的行为路线。通知涉及写入结果，另执行真实页面上传、移动、删除、失败和续办，并独立查询数据库及 Storage。

- 目录切换、搜索、排序、分页、刷新：保留目录树和工具栏，只在右侧文件区显示加载动画。普通查询失败显示“重新加载”；收到权限不足的响应时清除旧资料。
- 加载期间使用浏览器返回：中止较早的查询，序号校验阻止旧结果覆盖当前位置。加载期间仍可展开、收起目录树，刷新后手动折叠保持。
- 成功上传、成功批次：默认收起明细。失败与未完成项默认展开，保留继续核对入口，明细最多占 160px 并独立滚动。所有操作通知位于资源管理器下方。
- 桌面文件区按窗口高度分配，文件与目录树各自滚动；移除页面重复内边距。窄屏保留 384px 文件区，工具栏和分页正常换行，长路径在自己的区域滚动。
- 选中条目后显示批量按钮；操作栏保持固定高度，按钮较多时横向滚动。选中前后条目位置一致，防止第二次点击错位而无法双击打开。分页避开右下角助手。
